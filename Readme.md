
# 📝 JavaScript To-Do List Project

## 📌 Project Description
This is a simple and user-friendly To-Do List application built using HTML, CSS, and JavaScript.

It helps users manage their daily tasks easily. Users can add new tasks, delete individual tasks, and clear all tasks.

## 🚀 Features

- Add new tasks.
- Delete individual tasks.
- Clear all tasks.
- Save tasks using LocalStorage.
- Automatically load saved tasks after refreshing the page.
- Attractive and responsive CSS design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## ⚙️ How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the index.html file.
4. Run it using Live Server or open it in your browser.
